# 普通弹窗取消通道：I-006D8 计划

状态：计划中。底层控件和项目绑定器的取消已实现，不等于普通 RA_FILL 消息可取消。

采用固定具名 chrome.tabs.connect 端口，目标仍为当前顶层内容脚本。只接受本扩展 popup.html / options.html 的真实 sender；网页、其他扩展、缺来源及错误名称不能调用。每个端口仅接受一个严格填写或稳定扫描请求，没有选择器、脚本、档案或导航能力。

网页持有 AbortController；弹窗停止、关闭或档案/连接变化会断开端口，触发该控制器。预取消在连接前检查，监听建立后再次检查；一次请求只允许一个结果。未知、重复、超长请求与连接超时直接停止，不重试或放回不可取消的旧消息。

端口填写与旧普通消息、项目任务和中国移动任务共享页面占用锁。取消后等待正在执行的批次真正结束才释放锁，不能让迟到的 finally 清除新任务。断开后不发送成功消息，取消不回滚已经接受的操作，也不签发项目保存权限。

稳定扫描也绑定原 URL 和信号，取消不能产生可供后续填写的新扫描。完整字段与格式保护仍由原 fillScan 负责；该端口只把取消送达，不改变候选取值规则。

验收先验证预取消零连接、端口断开清理、错误 sender、重复请求、占用冲突、超时、取消与响应同轮、恢复新批次不受旧清理影响。再以实际 MV3 的异步选项验证停止/关闭弹窗/改档案后零迟到点击、零后续字段事件，并重跑完整检查和所有浏览器回归。
