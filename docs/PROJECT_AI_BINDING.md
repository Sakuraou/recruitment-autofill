# AI 字段含义与当前项目

v0.6.7 已将当前项目取值契约、有界异步识别和可信后台 Port 接入生产项目连续流程，完整检查和浏览器回归通过。已连接 AI 时，当前编辑器真正未知的字段先整批识别，再本地取值和校验，由原绑定器填写、原规划器保存。未连接或无法确定时保留草稿并停下。普通 AI 入口没有当前记录规划的凭据时仍不读取任何一条项目。

## 当前项目取值契约

模型继续只返回白名单路径，例如 `projects.description`，不能返回记录索引、项目名称答案、控件选择器或动作。当前具体项目只来自本地记录规划器已签发的 populate-editor 步骤和活动事务。不是按页面第几个输入框推测，也不是默认档案第一条。

建立私有上下文，签发与使用时均检查：

- 运行上下文仍活动、原始 capture/plan/transaction 均有效，没有被消费、停止或替换。
- 捕获是该运行的最新观察，档案和编辑器修订未变；字段集合与已观察的当前编辑器完全对应。
- 规划器的 intentIndex 在本地档案内有效，项目 ID 不重复；所有候选均属于这次 populate-editor 的字段范围。
- 语义绑定仍为原始本地凭据，当前扫描和档案未变；克隆/JSON/伪造对象没有效力。
- 原 DOM 目标仍在同一编辑器内，控件映射仍指向原节点；静默改值、标签、长度或选项变化也会使上下文失效，不依赖网页一定派发 input 事件。

私有上下文对外只显示记录类型，不暴露个人答案或项目索引。具体值在本地由当前项目读取。日期精度、进行中、字数、URL、选项唯一匹配和控件格式沿用项目规则的共同校验。缺值不生成答案、超长不截断、模糊选项不提供可写值；保持模型来源与候选状态。

测试使用两个不同名称/简介的虚构项目，由原规划器先识别第一条已存在，再规划第二条。候选只读取第二条；交给原绑定器后原上下文失效。无上下文、上下文克隆、停止/新 capture、原节点替换、静默修改、同修订号内容变化及日期/选项边界均拒绝生成错误可写值。此层只产生候选，不能写 DOM 或签发保存权限。

## 接入记录流程

私有当前项目上下文已接入现有有界异步识别接口。准备请求之前限定当前编辑器字段，缓存读取后、模型返回后和缓存写入后重新检查上下文；停止、手改、换节点或修订变化不允许返回旧候选。跨编辑器字段不能顺带进入项目请求。项目连续入口目前不启用含义缓存，每条编辑器只允许一批未知字段，不重试。

只在已授权项目任务的当前编辑器存在真正语义缺口时调用模型；已认识但缺事实、日期精度不足或协议字段不调用。未知字段应先整批理解和本地校验，全部必填项可处理后才进入原绑定器写入，保留原子写入、回读、回滚和保存后记录身份核验。

内容脚本继续只获取最小项目投影。提供方通过可信后台和固定本机服务调用，配对令牌不会交给网页或内容脚本。新的消息契约必须限制来源、形状、批量、时间与取消，不允许消息指定 URL、索引、原答案或动作。关闭弹窗后继续、停止时取消和重启去重仍须实际 MV3 验收。

后台传输与执行：

隔离 MV3 探测已确认 activeTab 授权下可读取自身顶层 Port 的 frameId、活动文档和当前标签页 URL，不增加权限。Port 断开取消设计依据 [Chrome 官方消息传递文档](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)；文档身份来自 [runtime MessageSender](https://developer.chrome.com/docs/extensions/reference/api/runtime#type-MessageSender)，不是请求体自报。

1. 使用具名 runtime Port，只接受自家扩展的 HTTP 顶层内容脚本；一端口一次严格语义请求，全部字段必须属于 creating/project。
2. 后台读取已启用连接并再次脱敏线索，固定本机提供方调用。拒绝调用方端点、凭据、个人值、索引或动作；限时、断开取消，不暴露异常详情。
3. 返回前复查连接、当前标签页与原文档；本地原语义会话和项目上下文再次验证，后台输出本身不能授权写入。
4. 项目驱动器先解析全部已知字段。缺事实或格式不通过直接保留草稿；仅真正未知的字段请求模型，全部当前字段有本地可用值后才进入原绑定器。
5. 使用虚构陌生项目页做实际 MV3 验收：六条名称/简介各异、后台调用不含资料、关闭弹窗继续、停止取消、迟到结果不写、保存去重和最终提交零次。

后台限制单标签页一个端口、最多八个并行端口、十五秒期限；严格形状、四万字符请求上限、一端口一次。再次遮盖完整本地档案中的字面值，返回前核对完整资料、连接与当前标签页；断开即取消提供方，迟到响应不再发送。不共享配对令牌，不复制供应商错误。页面内再次验证原私有语义会话、原节点和当前项目，未知字段必须全部具备可用候选才能写入，缺值/部分批次零写入。

模型不能随意点击按钮。新增/保存仍消费原规划器能力，删除、附件、下一步和最终提交保持原边界。暂停采用协作方式，当前步骤核验后暂停，恢复前重新核对资料和网页；关闭弹窗不取消项目任务，停止任务则断开端口。项目完成后再按相同方法扩展其他重复栏目和局部截图后备。真实模型质量和真实登录招聘页尚未验证，不能宣称所有页面兼容。
