# 长表单受控定位 · I-014N

开发控制器在 `src/content/visualFieldLocator.ts`，未被正式 content、popup 或消息协议导入。0.6.60没有自动滚动能力；此文件的独立检查不能替代正式安装验收。

## 已实现的本机流程

1. 原扫描、原生未知空字段、普通栏目与原标签需可核验。已知字段、经历编辑器、已有值、只读及未知布局不定位。
2. 检查本机视觉候选登记；只要存在旧候选即拒绝移动，不能让旧截图凭据在新位置继续填写。
3. 获取独立的新页面lease。其他任务正在拥有页面时拒绝，不借用旧截图或文字推理的lease。
4. 原字段和全部原标签必须能同屏。拒绝嵌套滚动和不可达目标；只用本机原矩形计算一次window原生滚动，不接受选择器、坐标或模型动作。
5. 等待位置稳定，观察原DOM、用户事件、Stop、导航及节点/扫描替换。中断后保留当前位置和手改，不回滚页面，不填写。
6. 按实际滚动差值投影原图的viewport边界，继续调用原有完整扫描核验器，保留字段、节点和图关系比较。原扫描本身仍然失效；不会删除几何检查或改变全局核验规则。
7. 重新扫描，返回同一原节点的新字段引用，再释放拥有者。返回值不提供图像、裁剪、模型或填写权限；正式调用者以后必须安装新扫描、重新匹配及重新申请图像许可。

一个控制器实例最多移动一次；原来可见时不滚动。正式调用方尚未提供，因此候选登记检查目前通过本机依赖接口注入，不能从页面或模型消息读取布尔值。
