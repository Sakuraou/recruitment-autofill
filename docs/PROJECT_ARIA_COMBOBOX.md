# 当前项目的稳定 ARIA 组合框：I-006D9 计划

状态：计划中。普通逐字段组合框已有控件验证；项目绑定器仍主动拒绝该类型，不能仅删除禁用条件。

代码审查发现 stableAriaComboboxListbox 当前按 ID 找第一个元素，尚未显式拒绝重复 ID。执行轮次先补失败夹具，核验唯一 ID、唯一控件归属及列表/选项身份，再决定项目准入；完整验证期间不改源代码。

优先验证实际点击路径的默认激活：role="combobox" / role="option" / ARIA 单选与勾选可以被放在 submit/reset 按钮或链接上，ARIA 名称不能取消其原生行为。先用带提交、重置、导航计数的隔离夹具验证；若确有动作越界，按计划优先级先独立修复并完整回归，再继续准入。不得通过禁用网页事件或伪造成功规避问题。

首轮范围限定为主文档当前项目中的稳定组合框：原节点有明确标签，唯一 aria-controls/owns 关联已经存在的 listbox，选项可观察、答案唯一且启用。列表和选项由内部 DOM 观察绑定，不能依赖模型提供选择器或第一个选项。列表可折叠，常规展开、选中及回读状态变化可以发生；节点、关联、含义或选项身份改变时拒绝旧绑定。虚拟列表、级联、新建/重挂载列表和自定义日历另行迭代。

预检必须在任何填写前完成，包含当前项目本地事实、字段原观察、唯一匹配及原编辑器范围。写入使用现有可取消适配器；回读、联动静默等待、新捕获、最终字段回执及保存前观察都保持原节点和选择含义。一次打开和一次唯一选项点击不授予 Save，也不授予再次 Add。

组合框没有通用的安全清空动作。后续字段失败或取消后，不能用直接属性赋值、选另一个答案、点击清空或取消整个表单假装回滚成功。保留网站接受的组合框值，拒绝保存并准确报告可能不完整的回滚；原生字段继续沿用保护手改的恢复逻辑。异步回写尚未可见时也不能武断报告全部已撤销。

先建立当前第二个项目的已知/AI 角色组合框、已有相同值、冲突、重复/禁用选项、列表和选项替换、用户选择、停止、延迟回读、后续失败及保存前静默手改夹具。普通控件默认保持原行为，项目首轮稳定选项观察不允许在打开时重建选项。完成内部契约后，以真实 MV3 验证连续不同项目和联动新字段，恰好一次 Add/选项/Save、危险动作零，再完整回归。
