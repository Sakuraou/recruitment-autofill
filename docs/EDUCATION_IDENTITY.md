# 教育卡片身份与填写顺序 · I-007B

状态：planned。I-007A 完整回归并提交后开始；这一轮仍不开放教育新增/保存入口。为后续事务准备页面内只读比较器和确定填写顺序。

卡片身份只读取可见、完整、属于本卡片的学校、教育阶段、专业和明确日期。先支持标题加明确段落、定义列表和两列表格三个布局族；不按 CSS 类名、夹具 ID 或模型生成选择器判断。字段标签必须指向对应事实，任意卡片整段文本不能当作学校名。隐藏/inert/CSS 截断、控件值、嵌套卡片、多个冲突标题或字段不给身份。

学校是主证据，另须独立阶段、专业或完整同精度起止日期证据。所有已观察且双方已知事实都要对照；冲突不能被另一项一致证据掩盖。同校不同阶段/专业、不同完整时间段应区分；同名记录或一对多仍由规划器拒绝歧义。单张卡片不同学校可判 different；学校相同但证据不足、未知事实、精度混合或冲突来源保持 insufficient。

日期支持真实公历年月或年月日，只有双方精度一致且值相同才能作为日期证据；月份不补具体日。完整时间段双方可证明不同才授予不同记录结论，片段冲突保持 insufficient。进行中使用已经确认的状态与唯一至今文本，不能按空结束日期或当前日期推算。结果仅返回 verdict、signals 和 rule 来源，原学校/专业/日期只在页面内临时存在，不进入语义图、日志、消息或模型。

填写顺序对教育最小投影建立独立索引计划，本科在硕士之前，专科、博士分别按阶段级别处理；相同阶段保持原顺序，不修改资料。其他/未知阶段、重复 ID 或无可靠学校时拒绝生成顺序。最高学历/学位布尔规则另建完整集合契约，不能因为排序靠后就猜测取得学位。

先建立正常三布局、源顺序为硕士/本科、已有卡片乱序、同校不同阶段/专业/日期、月份精度、重复/冲突、隐藏/截断/嵌套、未知或进行中日期、无动作和无个人值输出专项。接入只读比较和顺序后，运行项目身份、图结构与新模块专项，再完整回归。当前生产入口保持原状；下一轮才能绑定教育事务、本地当前条目和保存回执。
