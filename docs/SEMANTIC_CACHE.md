# 字段含义缓存

此文档记录 I-006D2 / I-006D3 的实现边界和后续验收。缓存只是已核验字段含义的复用，不能授权点击、保存或提交，也不保存个人填写答案。

## 内存原型

只有当前扫描和档案下由本地校验器签发的原始凭据才能写入；克隆、伪造、已过期或已改变上下文的凭据均无效。命中需重新签发会话、重新检查网页，再从当前档案取值。保持模型来源，使用原日期、长度、单位和唯一选项验证。

页面路由、扩展版本和不透明档案修订号隔离缓存。结构图、栏目、字段短线索、控件类型、完整可见选项及禁用状态必须一致。内部选项代码不缓存，由当前网页重新读取。超过 40 个选项的截断观察不学习。最多保留 100 个含义，十分钟过期，时钟倒退拒绝，整批命中才复用。

I-006D2 原型的缓存对象仅存在于调用者内存；v0.6.5 的生产弹窗使用下述会话实现。当前完整验证状态见 PROJECT_PLAN.md 和 VERIFICATION.md。

## 浏览器会话版本

- 使用 `chrome.storage.session`，显式限 TRUSTED_CONTEXTS；不会进入档案备份或浏览器同步。浏览器重启、扩展禁用、重载或更新后清空，依据 [Chrome 官方存储说明](https://developer.chrome.com/docs/extensions/reference/api/storage)。
- 存储紧凑的结构观察摘要和白名单路径，不存原 URL、线索原文、控件 ID、选项内部值、图片、个人答案、API 密钥或配对令牌。路由摘要仅用于本地隔离，不发送模型。
- 用独立随机会话密钥签名存储包，严格校验形状和上限，篡改或不完整存储不能产生候选。会话密钥不是 API Key，与配对令牌无关。
- 可信扩展上下文使用同一 Web Lock 串行读写和清空，避免两个弹窗或后台清空互相覆盖。档案、连接改变时清空；旧操作仍受取消和完整当前上下文核验约束。
- 存储不可用、签名失败或任何字段未命中时，回到正常模型流程；不放宽验证，不拼接部分缓存去挽救非法模型响应。
- 已用虚构模型完成关闭/重开弹窗零调用、篡改回退、档案变化读取最新值和关闭连接清空的实际 MV3 专项；真实模型质量和登录招聘站点仍需后续验收。
