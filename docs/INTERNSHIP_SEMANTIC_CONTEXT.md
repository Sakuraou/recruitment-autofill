## D1：固定目录和页面私有上下文

新增独立协议 3，只允许当前 creating 实习编辑器字段，不改变协议 1 的普通／项目请求或协议 2 的教育请求。固定路径为 internships.organization、department、role、startDate、endDate、description、achievements、experienceType、workType、companyProperty、monthlySalary、hasProof，共十二项。id、资料修订、endDateFact、数组索引、联系人／证明人及任意属性路径不进入模型目录。

页面私有上下文使用 WeakMap，绑定当前严格最小投影、原列表／编辑器／字段对象、原事务与捕获能力，完整核验当前 DOM 与资料。上下文的公共对象只含栏目类型；模型不能指定哪条经历、生成答案或授权动作。结束事实只供本地取值器判断至今和具体日期。

模型只得到未知字段的可见标签、有限控件类型、匿名选项、固定栏目和 creating 状态；已知事实直接处理。不能把存在性题映为当前条 hasProof；联合问题、已取得状态、薪资口径转换、联系人、上传、协议或验证码都须在本地前置拒绝，模型结果不能改变这些判断。选项只按当前条明确事实匹配，未提供事实不补造。

D1 验证旧协议目录与序列化兼容；新目录完整固定且不可更改顺序、增加索引或混合栏目。新私有上下文验证伪造／复制对象、过期捕获、换条、同修订修改、字段移动、完整 radio 成员、已知事实及存在性边界。先保持内部能力，尚不开放生产实习 AI。

## D2：生产端口和逐条闭环

在现有共享记录语义端口预算中增加实习类型，保持同一任务表、8 个总在途、每标签一条、单次使用、40k 请求和 15 秒期限，不能另开实习专用预算绕过教育／项目互斥。鉴别真实扩展发送方、活动主 frame、documentId 与标签 URL；连接变化、档案变化、用户 Stop、导航或端口断开取消本轮，迟到结果不得写回。

更新本机伴随服务的协议解析和严格目录格式。旧服务拒绝协议 3 时停在陌生字段待办，保持已知资料与草稿，不猜填。使用本地虚构模型验证，不接入用户 API 密钥或云账户。

实习驱动只把语义未知且可处理的字段发给模型，全部提议完整、当前上下文与资料仍一致后，本地十二事实取值器把对应条目答案交给原记录 binder。保持 C2a 的整条预检、三批内动态展开、回读和 Save 后身份核验；下一条重新创建自己的上下文。某条缺资料／提议不完整或手改时停止本条，不能借上一条答案。
