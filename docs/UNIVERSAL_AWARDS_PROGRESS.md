# 通用奖励栏目：实现与验证

更新时间：2026-10-12，正式安装包 **v0.6.44**，已接入内容脚本、独立奖励面板和Agent。

通用奖励已接入实际扩展和兼容API Agent：在唯一明确的奖励栏目中，按全部本地奖励逐条新增、填写、回读和保存，跨年度同名奖学金独立去重。支持明确原生存在性题、学生干部题及答题后动态描述；干部身份仅取明确档案事实。普通字段加教育、项目、实习和奖励共五类任务，固定消息、页面锁及Agent拥有者取消覆盖奖励，重新启动用当前DOM身份核验。

运行Agent需要本机兼容API连接，并保持弹窗打开；关闭或停止会取消后续动作。独立「连续填写全部奖励」入口可在关闭弹窗后继续，重开后查询、暂停、继续和停止。两种入口共用页面写入互斥。

## 当前范围

- 全部奖励从最小私有投影读取，包含每条学校、级别、日期、描述及明确干部事实，不发送给模型。
- 明确唯一主文档奖励列表、已核验添加与保存，以及原生是/否下拉/单选。
- 学生干部描述使用已有文本，联动新字段观察稳定后重新核验再保存。
- 既有卡片按完整名称、具体日期与辅助事实比较，同名跨年独立处理；不依靠数量判定完成。
- 未知题、缺事实、已有冲突、保存不明确、节点/资料变化或取消保留草稿与待办。

陌生奖励字段现在可由模型解释8个固定含义，必须绑定当前条的原事务、编辑器和控件，答案只从本地投影读取。模型不能返回事实或记录索引；已知缺事实、已有冲突、含义不明确仍保留待办。特殊日期/级联、自主探索未知按钮尚未开放；最终投递、验证码和附件由用户处理。不能据此宣称所有招聘网页都可填写。
