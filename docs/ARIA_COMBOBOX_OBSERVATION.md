# 稳定组合框内部观察 · I-006D9b

状态：已验证，生产包 v0.6.12；尚未开放项目填写。已先复现同名选项、原列表、共享归属、打开时重建和记录保存前的五项失败，以及回读就绪后微任务替换仍报告成功。24 项新增专项、136 项相关、54 文件 1185 项完整 check 及全部 E2E 9/27/17/28/14/9/7/22 通过；新增四项实际 MV3 场景，外部请求/页面异常/危险动作零。

先用同名选项重挂载、原列表替换及另一个组合框认领同一列表，复现当前逐字段指纹无法识别 DOM 对象替换的问题。普通异步空列表原有行为保持；首轮稳定观察要求已经存在非空选项、一个显式列表引用、唯一 ID，以及唯一组合框归属。

观察只由内部函数签发，存在页内 WeakMap 中；扫描结果、模型请求、消息、报告和存储不包含 DOM 引用、选中值或观察令牌。观察绑定原控件、树根、原列表及有序原选项对象和选择含义。相同文字或 ID 的新对象不能替代原对象，列表被另一控件认领也会使观察失效。

实现将唯一归属纳入显式列表查找；扫描对已有非空选项签发不含数据的页内令牌，并给适配器附加原对象检查。当前字段指纹、AI 返回前扫描复核及记录保存前比较使用原观察；列表和选项引用不会序列化。观察最多包含 1000 个选项及每个选项 256 层中间容器，超过范围不给项目未来准入能力。

允许正常折叠/展开和 aria-selected 状态变化，仍在行动边界检查可见、启用、原生激活限制和唯一匹配。稳定观察的选项增删、重排、标签、值或禁用状态变化均需重新扫描。已有答案沿用不覆盖策略；观察比较不以当前答案判断结构，填写回读和字段指纹继续独立检查值。

具备稳定观察的控件在打开前、打开后、唯一选项点击前、回读和记录新观察比较时验证原对象。没有稳定观察的普通异步组合框保留原有有界适配器路径；项目未来准入必须要求完整稳定观察，不能因此开放所有自定义控件。

本轮仅建立和验证观察，后续独立接入项目绑定器、联动等待与保存回执。没有通用清空动作的组合框在后续失败时不得假称回滚完成，也不能授予额外 Add/Save。

取消浏览器夹具原先打开后删除并重建原选项；新稳定观察正确地更早拒绝此行为，无法继续检验取消等待。因此夹具改为保留原选项对象、延迟恢复显示，停止/关闭/改档案仍需等待选项真正可见后断言零点击。重建选项通过独立实际 MV3 场景核验拒绝，未放宽旧取消断言。

专项按四组验证：

- 准入：唯一控件/列表、非空真实选项、重复 ID、多个显式引用、两个控件共用列表、克隆或伪造观察。
- 连续性：原列表/选项/中间容器替换、同名重挂载、重排、删增、静默改标签/值/禁用状态；展开/折叠及正常选中状态不应误判。
- 执行：扫描后替换、打开时重建、等待回读时替换或取消，旧观察零选项点击或准确拒绝成功；合法展开一次、选择一次。
- 边界：普通空列表延迟选项继续可用；消息/语义请求不包含观察；记录保存前的新观察必须对照原列表/选项对象。项目绑定器的拒绝条件保持。
