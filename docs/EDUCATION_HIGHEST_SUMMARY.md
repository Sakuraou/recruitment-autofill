# 普通个人信息页的最高教育摘要 · I-007E3

状态：planned。I-007E2 完整验证并提交后实施，不改变教育连续事务的当前记录选择。

## 已发现问题

profileResolver.educationValue 在最高摘要中只比较 level，再从该记录读取 degree。博士学历可能仅填写硕士学位；另一条记录也可能有更高的明确学位。最高学位应比较完整集合的 degree，不能沿用最高学历的位置。学习形式未知和“统招”也不能充当全日制。

## 范围与边界

复用 educationHighestFact 的完整集合、有限独立等级和未知结果。普通最高学历及其学校、专业等关联字段按学历维度选择；最高学位只按学位维度选择。明确全日制最高学历按学习形式筛选后比较学历。源数组不排序，不改变事实，索引仅由本地解析器产生。

最高候选唯一才可读取其学校、专业、成绩等不同事实。相同最高学历的摘要可以返回共同等级；多个同级学位但学位名称不同保持待办，不默认第一条。明确无学位、缺学位、陌生/否定/预期学位名以及未知教育阶段保留区别。已取得、已毕业和组合问题不从结束时间推断。

当前记录“是否最高”的布尔、普通最高摘要和明确本科/硕士记录字段分别处理；普通摘要不能扩大模型白名单，也不能为教育编辑器选择记录。原匹配器的保护字段、保留已有值、选项唯一性、字数限制与重复字段防重保持。

## 执行提示词

先读本契约、educationHighestFacts、profileResolver、ruleMatcher 和 matching 测试。新增失败测试：学历与学位不同最高、源顺序翻转、低学历缺学位不能忽略、其他未知阶段、同级最高但学校不同、全日制本科与非全日制硕士、统招不代替学习形式及已取得问题。最小修改普通摘要解析，明确阶段字段保持原语义；只返回原事实与确定共同等级。专项检查后实际 MV3 的普通最高学历/最高学位下拉各自选对，完整 check/E2E 后更新计划、验证记录和安装包版本，再推进其他通用重复栏目。
