# 受控语义模型迭代契约

## 当前能力

I-006A/B 建立只读绑定、本地取值和有界接口，I-006C 完成固定伴随服务，I-006C2 接入可选生产连接，I-006D1 增加最多三轮联动填写，I-006D2/3 接入已核验字段含义的浏览器会话缓存，I-006D3a 以独立随机连接修订隔离重连。`src/ai/semanticBinding.ts` 不包含网络、DOM 写入、存储、日志或点击操作。模型服务未配置不影响 v0.6.6 的规则填写与连续项目能力。

模型只回答字段含义。例如“如何称呼您”可提议绑定 `basic.name`；申请人的姓名仍由后续本地取值模块读取。模型不能补造个人答案或选择第一个项目。

## 请求

从扫描器完整且有效的语义图出发，只挑选规则仍未知的可编辑空字段；已知但缺值、标签冲突、家庭联系人、协议、认证和不支持的控件不作为模型语义缺口。

请求只包括随机请求号、固定路径目录和最多 30 个字段。字段内容为重新分配的引用、结构指纹、固定控件类型、规范栏目与新增状态，以及短的标签/ARIA/表头/标题/提示语。最多 40 个选项仅提供重新分配的引用和可见标签；更多选项不发送，而非截取前几个当作完整列表。长标签不截断后发出。

已知档案字面值在长度检查前遮盖，同时遮盖标签中的邮箱、URL、长号码和日期。此遮盖针对已知资料和这些可识别格式，不承诺识别网页上所有未知人名；生产服务入口必须清楚说明发送的是这些短线索。原页面 URL、页面标题、字段机器 ID、字段原引用、内部选项值、周围叙述、已有值和档案修订号均不发送。请求不包含任何完整档案内容或个人值的摘要。

原始扫描与档案观察仅留在扩展可信内存的私有 WeakMap。请求对象和子项冻结；外部用相同 JSON 构造的对象不是已签发会话。

## 响应

使用 Responses API 的严格 JSON Schema 格式：[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。每个对象禁止额外属性并明确列出全部必需属性；本地再校验长度、枚举、UUID、节点引用、指纹与重复项。

模型只返回请求号、有限状态，以及字段引用/指纹/白名单路径/确定性/证据枚举。禁止自由文本解释、个人值、选择器、脚本和动作。模型自己说“确定”不能跳过本地规则。

状态为 unresolved/refused 时绑定须为空；存在不确定绑定时整批不进入取值。未知字段引用、动作引用、重复引用、归属冲突及非法数据均拒绝整批，不保留其中看似正常的项。

项目逻辑路径只允许指向语义图已证明的 creating 项目编辑器；摘要、编辑已有记录、未知编辑器和普通个人栏目均无此能力。此轮不开放其他重复集合的模型路径。

## 新鲜度与执行

会话一次消费、最多 120 秒；扫描号、URL、图、字段观察或本地档案任一变化即失效。没有随机修订号的旧档案也比较完整本地内容，不能因时间戳相同漏掉变更。

通过响应校验只得到语义绑定。后续本地取值仍要核验事实、单位、长度、日期与选项，并通过现有内容脚本的实时字段回读执行；此模块本身不能证明当前 DOM 没有变化，也不能直接填写或点击。连续新增/保存依旧由记录规划器签发有范围的步骤，而非交给模型任意点击。

## I-006B 本地取值设计

通过响应验证的原对象由私有 WeakMap 记录凭据；JSON 克隆或伪造 `ok:true` 没有凭据。取值前再次比较扫描、字段与完整本地档案，同一修订号下的内容变化也会失效。

候选复用原事实读取、文本版本选择和普通填写的共同格式校验。厘米/千克单位必须来自原可见线索；日期不补日、数字不推算、文本不截断。选项按唯一可见标签或明确等价匹配；模糊和重复选项不提供值。所有这些候选保留 llm 来源及 review 状态，选项别名不能把来源改成规则。项目提议没有规划器的当前经历时不读取任何一条项目。

模型接口一次调用，整体最长 30 秒，可由调用方取消；默认 15 秒。超时或取消会发出 AbortSignal，迟到响应不再产生候选。不复制服务错误内容、不自动重试、未配置时不调用网络；确定性字段仍可正常匹配。`ready` 表示候选分析完成，不表示网页已填完。实际填写仍通过已有实时回读执行器。

## 固定伴随服务的实现顺序

先实现无 UI 的服务核心与虚构响应测试，再加生产扩展连接入口，避免未验证的通道直接参与填写。

- 服务只监听 loopback 固定地址；不支持网页或模型更改上游 URL，API Key 只由本机模型配置或服务启动进程的环境配置读取。
- 每次服务启动使用独立配对令牌；扩展只保存此本地令牌与启用状态，不能保存 API Key。浏览器普通网页不能读取可信扩展存储。
- 请求来源只接受有效扩展 Origin，且仍须配对令牌；普通网站、没有来源或未认证请求不能调用模型。CORS 不使用通配符。
- 严格解析最小请求，拒绝额外属性、原档案、任意路径、脚本/动作/URL 选项；请求体、选项、字段与并发都有上限。
- 原 Responses 提供方使用固定端点与 Structured Outputs；兼容提供方使用本机明确配置的 Chat Completions 地址和 JSON 输出。拒绝、不完整输出、非成功 HTTP、超时和多个不一致输出块均返回有限状态；不把供应商错误或自由文本传给扩展。
- 测试以注入的虚构 fetch/provider 完成，不读取现有真实密钥、不调用真实 API。随后在隔离 MV3 浏览器中验证扩展连服务、陌生字段、本地取值、过期响应和原规则回退。

开发命令为 `npm run semantic:serve`，只监听 `127.0.0.1:43127`；启动后将本轮配对令牌写入被 Git 忽略的 `artifacts/semantic-connection.local.json`。没有模型配置时不调用 API；要调用时由启动进程的 `OPENAI_API_KEY` 和 `RA_OPENAI_MODEL` 配置明确支持严格结构输出的模型，当前不预设模型或凭据。生产扩展须在“AI 识别连接”导入此文件并显式点击 AI 填写，不能将启动服务视为已启用。

扩展 CSP 仅新增固定 loopback 连接，不加宽泛主机权限；服务以准确扩展 Origin 的 CORS 和配对令牌验证请求。连接设置独立于档案和 JSON 备份，存储访问限 TRUSTED_CONTEXTS。每轮先运行最多四轮普通规则，再处理未知字段，只有本地已确认取值且唯一精确匹配的候选才由这次整体填写意图批量确认。实际有写入进展后等待 750ms 静默窗口、最多 3 秒稳定检测，再重扫，最多三轮 AI。已绑定但缺值的相同字段在本次操作里排除，不反复付费请求；这种排除只在内存，不是跨操作配方缓存。

返回后 RA_VERIFY_SCAN 重新扫描，不保留随机引用变更，但比较实际控件及单选成员的节点身份、完整字段观察、私有值指纹和语义图；同时核对标签页、URL、档案与连接。全部等价才保留原不透明引用供写入；替换、手改、导航或新字段均使整批失效。停止、关闭弹窗、档案或设置变化取消请求；已经发出的填写步骤仍由原执行器核验，不会撤销已填内容。全程绑定原标签页、URL 和完整档案；新轮次重新签发模型会话，不复用旧响应或值。会话缓存仅复用已验证含义，每次仍创建新会话、复查真实 DOM 并本地取值；最多 100 项、十分钟、整批命中，结构或选项改变失效，修改档案/连接清空。签名包只有结构/路由摘要、白名单路径和时间，不含个人答案，存储限 TRUSTED_CONTEXTS，不跨浏览器重启。详见 [缓存契约](SEMANTIC_CACHE.md)。当前不做截图或自主按钮探索，实际云模型尚未调用验证。

原 Responses 上游设置 `store:false` 且没有模型工具；兼容上游的保留设置以供应商为准，不发送模型工具。这些请求设置不意味着供应商所有保留政策都关闭。模型输出只通过有限状态和严格绑定回传，服务不写请求日志、不复制错误内容。测试已验证认证、预检、原始 Host 伪造、大小/并发/超时、断开、拒绝/不完整/多输出/非法 JSON 和输出再核验。

## 当前项目连续流程（v0.6.7）

已授权的项目连续任务在规则识别出现真正未知字段时，使用原本地 Planner/transaction/capture 签发当前项目上下文。每条编辑器最多一批模型请求，全部已知字段先校验；缺资料、精度不足或选项不确定不请求模型。模型只返回当前字段的白名单含义，记录索引和具体答案不外传、不默认第一条；全部候选有值后，才调用原原子绑定器和保存核验。

内容脚本通过固定具名 Port 请求可信后台，后台保管配对令牌，并用完整资料再次脱敏。只接受自家扩展的顶层活动 HTTP 文档、严格 creating/project 请求，一端口一次、单 tab 一次、最多八个并行端口、十五秒期限。返回前核对连接、资料和 tab，页面端再核对原节点和当前项目。关闭弹窗仍继续，停止断开 Port 并取消提供方；协作暂停等待当前步骤核验后暂停。此入口不共享弹窗语义缓存，不扩展模型动作权限。详见 [当前项目契约](PROJECT_AI_BINDING.md)；验证仍以虚构提供方为主，没有实际云模型质量保证。
