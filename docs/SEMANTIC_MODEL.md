# 受控语义模型迭代契约

## 当前能力

I-006A 建立只读请求和响应校验模块，尚未接入云服务或生产弹窗。`src/ai/semanticBinding.ts` 不包含网络、DOM 写入、存储、日志或点击操作。模型服务未配置不影响 v0.6.2 的规则填写与连续项目能力。

模型只回答字段含义。例如“如何称呼您”可提议绑定 `basic.name`；申请人的姓名仍由后续本地取值模块读取。模型不能补造个人答案或选择第一个项目。

## 请求

从扫描器完整且有效的语义图出发，只挑选规则仍未知的可编辑空字段；已知但缺值、标签冲突、家庭联系人、协议、认证和不支持的控件不作为模型语义缺口。

请求只包括随机请求号、固定路径目录和最多 30 个字段。字段内容为重新分配的引用、结构指纹、固定控件类型、规范栏目与新增状态，以及短的标签/ARIA/表头/标题/提示语。最多 40 个选项仅提供重新分配的引用和可见标签；更多选项不发送，而非截取前几个当作完整列表。长标签不截断后发出。

已知档案字面值在长度检查前遮盖，同时遮盖标签中的邮箱、URL、长号码和日期。此遮盖针对已知资料和这些可识别格式，不承诺识别网页上所有未知人名；生产服务入口必须清楚说明发送的是这些短线索。原页面 URL、页面标题、字段机器 ID、字段原引用、内部选项值、周围叙述、已有值和档案修订号均不发送。请求不包含任何完整档案内容或个人值的摘要。

原始扫描与档案观察仅留在扩展可信内存的私有 WeakMap。请求对象和子项冻结；外部用相同 JSON 构造的对象不是已签发会话。

## 响应

使用 Responses API 的严格 JSON Schema 格式：[Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。每个对象禁止额外属性并明确列出全部必需属性；本地再校验长度、枚举、UUID、节点引用、指纹与重复项。

模型只返回请求号、有限状态，以及字段引用/指纹/白名单路径/确定性/证据枚举。禁止自由文本解释、个人值、选择器、脚本和动作。模型自己说“确定”不能跳过本地规则。

状态为 unresolved/refused 时绑定须为空；存在不确定绑定时整批不进入取值。未知字段引用、动作引用、重复引用、归属冲突及非法数据均拒绝整批，不保留其中看似正常的项。

项目逻辑路径只允许指向语义图已证明的 creating 项目编辑器；摘要、编辑已有记录、未知编辑器和普通个人栏目均无此能力。此轮不开放其他重复集合的模型路径。

## 新鲜度与执行

会话一次消费、最多 120 秒；扫描号、URL、图、字段观察或本地档案任一变化即失效。没有随机修订号的旧档案也比较完整本地内容，不能因时间戳相同漏掉变更。

通过响应校验只得到语义绑定。后续本地取值仍要核验事实、单位、长度、日期与选项，并通过现有内容脚本的实时字段回读执行；此模块本身不能证明当前 DOM 没有变化，也不能直接填写或点击。连续新增/保存依旧由记录规划器签发有范围的步骤，而非交给模型任意点击。
