# 教育和项目的卡片标题身份

状态：planned；隔离 DOM 探针已复现。实习的同类修复已在 v0.6.22 完整验收。

## 证据与问题

已有教育卡片以“本科”为 h3、段落明确学历／专业，却没有学校标签；已有项目卡片以“开发成员”为 h3、段落描述与来源项目一致，却没有项目名称标签。两个读者把标题直接当成学校／项目名，判 different，随后各点击 Add 一次。探针随后因简化编辑器停止，Add 已发生；不能把后续停止当作防重复成功。

## 身份契约

- 明确学校／项目名称标签是主证据，可以独立区分来源外的另一名称；冲突标签保持不确定。
- 未标注标题只在严格、完整、有界、身份唯一的当前来源集合中核对学校／项目原文后使用。学历、专业、岗位、公司或通用文字不能仅因是 h3 就证明不同条。
- 学校／项目名称与来源中的其他意义同名时，未标注标题保留歧义；明确名称标签可以解决这种歧义。已核对的标题与明确名称冲突，不能选择其中一个。
- 私有快照保存名称证据，共享图、结果、日志和模型不包含个人值。修改 DOM、源资料、列表或编辑器后必须重新捕获。
- 保留教育独立阶段顺序、项目源顺序、同校不同专业／阶段、同名不同日期、进行中状态与保存核验。不降低已有动作和回读保护。
- 项目卡片位于外层申请 form 中时，应读取卡片内可见摘要，仍排除卡片内部编辑表单、隐藏／截断／其他卡片和过量文本。
